# 🚀 AI Career Chatbot

An AI-powered career advisory platform built with **Node.js, Express, React (Vite)**, and **PDF parsing capabilities**.

## 📁 Repository Structure

```text
Ai-career-chatbot/
├── Backend/          # Express API server (Resume parsing, LLM services, Career guidance)
├── frontend/         # React 19 + Vite client application
├── .gitignore        # Root gitignore rules
└── README.md         # Main project documentation
```

## 🛠️ Features

- **📄 Resume Analyzer**: Upload PDF resumes to receive feedback on strengths, weaknesses, missing skills, and improvement suggestions.
- **🧠 Career Guidance**: Input your skills and career goals to get career options, learning roadmaps, and recommended tools.

## 🚀 Getting Started

### 1. Backend Setup

```bash
cd Backend
npm install
node server.js
```
The backend server runs on `http://localhost:5000`.

### 2. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
The frontend application runs on `http://localhost:5173`.
